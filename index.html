Featured NASA Space Apps Challenge 2026 · “Flame in Freefall”

Flare AI

Evidence-graded fire safety from NASA microgravity data

I led a three-person team building Flare AI, a web tool that turns NASA's microgravity fire experiments into answers people can check. It brings together all 24 combustion investigations in NASA's Physical Sciences Informatics repository and 537 individual test records. Every value traces back to its NASA source, and our team checked every record by hand.

Role
Team lead, 628 Aerospace
Team
3 people
Recognition

Live site ↗ Source code ↗ 30-sec demo ↗
  • 24combustion investigations from NASA's PSI repository
  • 537individual test records, each checked by hand
  • 4experiment series: BASS, BASS-II, FLEX, Saffire
  • 3environments ranked: spacecraft, Moon base, Mars base

What I built and directed

  1. 01
    Data pipeline

    A Python pipeline that extracts NASA's test tables and checks them automatically against NASA's original reports and files on every build.

  2. 02
    Interactive site
    • Investigation rankings for spacecraft, Moon-base and Mars-base conditions
    • Like-for-like test comparisons that refuse mismatched data
    • A scenario checker that shows the closest real NASA tests
  3. 03
    AI research assistant

    Runs on Google Gemini through a serverless function. It answers only from NASA's records, cites every point, and says plainly when the data doesn't cover a question.

  4. 04
    Deployment and security

    Hosting on Netlify, a strict security policy, a server-side API key, usage limits, and automated browser tests.

  5. 05
    The submission

    A 30-second narrated demo video and the full submission write-up.

What I learned

  • Designing for scientific honesty. Never inventing numbers, and showing data gaps instead of hiding them.
  • Managing a fast-moving codebase through pull requests.
  • Directing AI coding tools (Claude) while keeping full ownership and verification of the work.
